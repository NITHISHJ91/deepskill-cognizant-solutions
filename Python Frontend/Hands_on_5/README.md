# Student Portal React

## Hands-On 5 – Task 1

This project is developed as part of the **Digital Nurture 5.0 - Frontend Development** program.

In this task, I created a simple Student Portal application using React and Vite. The main objective was to understand the basics of React, such as creating functional components and passing data using props.

### Features

= Created a Header component.
= Created a Footer component.
= Created a CourseCard component.
= Passed the site name to the Header using props.
= Displayed course details such as course name, code, credits, and grade using props.
= Used separate CSS files for styling.

### Technologies Used

= React
= Vite
= JavaScript (ES6)
= JSX
= HTML
= CSS

### How to Run the Project

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Install the required packages:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the following URL in your browser:

```
http://localhost:5173
```

### Learning Outcome

By completing this task, I learned how to create a React project using Vite, build reusable functional components, use props to pass data between components, and organize a React application into separate files.
